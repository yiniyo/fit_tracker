# 🏋️ 핏트래커 (InBody & Workout Tracker)

인바디 체성분 정보를 기반으로 현실적인 목표 체중 및 체지방률을 설정하고, **기초대사량(BMR) + 당일 수행한 운동량(종목·강도·시간/세트)**을 결합하여 **하루 총 소비 칼로리를 실시간 누적 계산**해 주는 개인 맞춤형 피트니스 트래커 웹 애플리케이션입니다.

---

## 🌟 주요 기능

### 1. 인바디 기반 목표 체중 & 체지방률 설정
- **인바디 실측치 입력**: 키, 현재 체중, 골격근량(SMM), 체지방률(PBF), 기초대사량(BMR) 입력 지원
- **BMR 공식 자동 계산**: 인바디 결과지가 없어도 Katch-McArdle(체지방률 반영) 및 Mifflin-St Jeor 공식으로 기초대사량 즉시 산출
- **목표 분석 & 가이드**: 목표 체중과 체지방률을 설정하면 **감량해야 할 순수 체지방량(kg)**, 안전한 권장 기간(주 0.5kg 기준 예상 주차), 일일 권장 칼로리 결손량(Deficit) 맞춤 가이드 제시

### 2. 자주 쓰는 운동 Pool (Quick Presets)
- 사용자가 자주 하는 운동을 원클릭으로 오늘 기록에 즉시 추가!
- **기본 등록된 프리셋**:
  1. `스텝퍼 (고강도 · 10분)` → **100 kcal**
  2. `트레드밀 (경사 3, 속도 4 · 5분)` → **35 kcal**
  3. `스텝밀/천국의계단 (레벨 8 · 10분)` → **120 kcal**
  4. `고블릿 스쿼트 (5kg 덤벨 · 15회 × 3세트)` → **55 kcal**
  5. `힙 어브덕션 (20kg · 15회 × 3세트)` → **45 kcal**
  6. `매달리기 (10초 버티기 × 3회)` → **15 kcal**
  7. `줌바 댄스 (고강도 · 50분)` → **420 kcal**
- **나만의 운동 Pool 관리**: `+ 새 운동 등록` 버튼으로 자신만의 운동 종목, 강도/무게/세트, 예상 칼로리를 등록하고 필요 시 언제든 삭제 가능

### 3. 유연한 맞춤 운동 입력 & 칼로리 실시간 누적 계산
- **시간/유산소 모드**: 운동명, 상세 설정(경사, 속도, 레벨 등), 소요 시간(분), 체감 강도(저/중/고/초고) 입력
- **세트/근력 모드**: 운동명, 중량(덤벨/머신 등), 횟수(회 또는 초), 세트 수(세트), 총 소요 시간 입력
- **스마트 칼로리 계산 & 직접 입력 지원**:
  - 체중과 METs 계수를 기반으로 소비 칼로리를 실시간 자동 계산
  - **'직접 입력'** 체크박스를 통해 스마트워치(애플워치/갤럭시워치) 측정 칼로리로 자유롭게 수정 가능
  - **'⭐ 자주 쓰는 운동 Pool에도 동시 저장'** 옵션 지원
- **실시간 칼로리 누적**:
  $$\text{오늘 총 소비 칼로리} = \text{기초대사량 (BMR)} + \sum \text{오늘 등록된 운동 소비 칼로리}$$

### 4. 일자별 트래킹 & 시각화 대시보드
- **날짜 탐색기**: 이전 날짜, 오늘, 특정 일자 선택 및 과거 운동 기록 조회/편집
- **오늘 총 소비 칼로리 KPI**: 실시간 누적 수치와 불꽃 게이지 표시
- **칼로리 구성 도넛 차트**: 기초대사량 비중 vs 운동 소모 비중 실시간 시각화
- **체중 & 체지방률 추세 꺾은선 차트**: 목표 체중선(점선)과 함께 일자별 체중 및 체지방률 추이 한눈에 파악
- **데이터 백업 및 복원**: JSON 파일 다운로드(백업) 및 불러오기(복원) 지원 (로컬스토리지 영구 보관)

## 📱 모바일 사용 및 무료 웹 호스팅 배포 (언제 어디서나 접속)

본 트래커는 **PWA(Progressive Web App)** 지원 및 모바일 터치 최적화가 완료되어 있어, 무료 웹 호스팅에 올리면 헬스장이나 야외 등 어디서든 스마트폰으로 접속하여 홈 화면 앱으로 사용할 수 있습니다.

### 방법 A: Netlify Drop (가장 추천 ⭐ - 30초 완성, 드래그 앤 드롭)
1. 브라우저에서 **[app.netlify.com/drop](https://app.netlify.com/drop)** 접속 (무료 회원가입)
2. Mac 파인더(Finder)에서 현재 프로젝트 폴더 (`/Users/yiniyo/Desktop/안프로/운동 추천`)를 브라우저 창의 점선 영역으로 **마우스 드래그 앤 드롭**!
3. 몇 초 만에 즉시 전용 HTTPS 주소(예: `https://my-fit-tracker.netlify.app`)가 생성됩니다.

### 방법 B: GitHub Pages 배포
로컬 git 커밋이 이미 준비되어 있습니다:
```bash
# 1. GitHub에서 새 Repository (예: fit-tracker) 생성 후 원격 연결
git remote add origin https://github.com/<사용자ID>/fit-tracker.git
git branch -M main
git push -u origin main
```
2. GitHub 저장소의 **Settings -> Pages**에서 Source를 `main` 브랜치로 설정하면 `https://<사용자ID>.github.io/fit-tracker` 주소로 무료 배포됩니다.

### 📲 스마트폰 홈 화면에 '앱'으로 설치하는 방법
배포된 웹 주소로 스마트폰에서 접속한 뒤:
- **iPhone (Safari)**: 하단 **공유 버튼(네모+화살표)** 탭 ➔ **[홈 화면에 추가]**
- **Android (Chrome)**: 우측 상단 **메뉴(점 3개)** 탭 ➔ **[앱 설치]** 또는 **[홈 화면에 추가]**
- 바탕화면에 '핏트래커' 아이콘이 생성되며, 브라우저 주소창 없이 **네이티브 앱처럼 전체 화면으로 구동**됩니다!

## 🚀 로컬 실행 방법

### 방법 1: 브라우저에서 바로 열기 (가장 간편)
`index.html` 파일을 더블 클릭하여 Chrome, Safari, Edge 등 웹 브라우저에서 바로 열 수 있습니다.

### 방법 2: Mac 터미널 명령어로 열기
```bash
open index.html
```

### 방법 3: 로컬 웹 서버 실행 (선택)
```bash
python3 -m http.server 8000
```
실행 후 브라우저에서 `http://localhost:8000` 접속

## 📁 파일 구성
- `index.html`: 메인 대시보드 UI (Tailwind CSS, 모달, 반응형 레이아웃)
- `app.js`: 데이터 처리, BMR 계산, METs 칼로리 엔진, Pool 관리, Chart.js 연동 로직
- `styles.css`: Pretendard 한글 폰트, 반응형 디자인, 마이크로 인터랙션 및 애니메이션
